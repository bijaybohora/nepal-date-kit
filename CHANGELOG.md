# Changelog

## 0.1.0 - 2026-11-03

Initial release.

- Convert Bikram Sambat and Gregorian dates for BS 2000–2100
- `NepaliDate` with arithmetic, comparison, fiscal year, and `Date` conversion
- Nepali and English formatting presets, token patterns, and BS string parsing
- Runtime loader for calendar data, plus a JSON Schema and validator
- Month grid ready for a UI, with a hook for external events
- `isVerifiedYear` / `getDateAccuracy` for years after BS 2086
